# SwaadBazaar - Online Food Ordering Website

SwaadBazaar is a simple **PHP-based food ordering website** designed for the Swaad Bazaar shop. Users can browse food items, add them to the cart, place orders, and make payments seamlessly.

## Features
- **User Authentication** (Register/Login using Local Storage)
- **Food Ordering System** (Add to Cart, Checkout, Payment)
- **Search & Filtering** for food items
- **Rating & Review System** (Integrated into food item cards)
- **Cart System** (View, Modify, Remove items)

## Pages
- **Home Page (`index.php`)** – Displays featured food items.
- **Menu Page (`menu.php`)** – Lists all available food items with search & filters.
- **Cart Page (`cart.php`)** – Shows selected items & checkout option.
- **Contact Page (`contact.php`)** – Contact form for customer queries.
- **Login/Register (`login.php`)** – User authentication system.

## Installation & Setup
### Prerequisites
- **PHP 7+**
- **XAMPP/WAMP/LAMP** (for local server)
- **Web Browser** (Chrome, Firefox, etc.)

### Steps to Run Locally
1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/swaadbazaar.git
   cd swaadbazaar
   ```
2. Start your local server (XAMPP/WAMP)
3. Place the project inside the `htdocs` (for XAMPP) folder
4. Open the browser and visit:
   ```
   http://localhost/swaadbazaar
   ```
